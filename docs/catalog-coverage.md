# LCBO 官网啤酒图鉴覆盖报告

快照日期为 **2026 年 11 月 8 日**。公共图鉴收录 **1,618 款独立酒款**，唯一数据来源是 LCBO 官网公开啤酒商品页。范围为 LCBO 安大略零售目录，包括本地酒、进口酒和无醇啤酒。[LCBO 官网啤酒集合](https://www.lcbo.com/en/collections/beer)

## 采集和归并

- 官网啤酒分类列出 **1,915 个商品编号**，均已核对相应商品页。排除 **51 个**其他饮料或混装商品。
- **1,864 个**合资格商品编号按品牌、酒名和酒精度归并。归入已有酒款的 **246 个**包装编号仍可搜索，并保留各自的官网链接。
- 结构化字段来自商品页以及 LCBO 官网列表中的分类信息。风格优先采用可用的具体分类，其次使用商品名称中明确写出的风格或网页风味风格。口味标签从官网品鉴描述提取。
